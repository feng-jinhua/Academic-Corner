# 学术成果目录主页
静态网页，用于展示个人学术成果目录，托管于 GitHub Pages。

## 项目介绍
本项目为纯静态HTML页面，无后端。
- `index.html`：成果目录主页面，包含政治经济学、编程经济学、西方经济学三类成果；
  支持页面内锚点快速跳转，成果简介可点击展开/折叠；成果标题嵌入Zenodo永久DOI链接。
- `about.html`：个人简介页面，可返回成果目录主页。

> 成果全文存档于 Zenodo，配备永久 DOI 标识符。

## 访问地址
GitHub Pages 在线预览：
`https://feng-jinhua.github.io/Academic-Corner/index.html`

## 使用方式
1. 本地直接打开 `index.html` 即可预览，无需服务器。
2. 修改成果条目：编辑 `index.html`，新增/修改成果信息、DOI链接。
3. 更新个人简介：编辑 `about.html`。

## 部署说明
使用 GitHub Pages 托管静态页面，文件放在仓库根目录。
提交代码后，GitHub Pages 将自动重新部署。
